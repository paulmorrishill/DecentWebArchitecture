# ISO/IEC 27001:2022 checklist

The 93 controls of **ISO/IEC 27001:2022 Annex A** (third edition, October 2022, with Amendment 1:2024, which adds a climate-change question to clauses 4.1 and 4.2 and no controls), and the management-system clauses 4–10. How to run the review is [33-security-review](../33-security-review.md).

ISO 27001 certifies an **information security management system**: the risk assessment, the Statement of Applicability, the policies, the audits and the reviews around the product. An architecture set cannot be that system. What it can be is the evidence for the technological controls — 8.25 to 8.29 especially, where a passed ASVS review is the evidence an auditor wants to see.

- **Repo rule.** ✅ a rule here, if followed, meets the item. 🟡 a rule meets part of it. ❌ no rule. ➖ the architecture as written has no such surface. 🏢 an organisational, people or physical control that an architecture cannot cover. **A tick is not a pass.** It says where to look; the reviewer still checks.
- **Tracker.** [iso-27001.csv](iso-27001.csv) has the same rows with empty result columns. Its rows are the start of a Statement of Applicability: every control needs a decision, included or excluded, with the reason.
- **Wording.** The control titles are ISO's; the notes are this set's. The standard is not free, and its text is the authority. Buy it before an audit.
- **The 2013 edition is gone.** Certificates to ISO/IEC 27001:2013 expired on 31 October 2025.
