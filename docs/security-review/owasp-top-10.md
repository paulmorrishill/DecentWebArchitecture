# OWASP Top 10 checklists

The OWASP Top 10 lists are awareness documents, not standards: each item is a class of weakness, not a testable requirement. Use them for two things — to brief the team, and to check after the [ASVS](asvs-5.0.md) pass that no whole class was missed. The named attacks to test for are in [attacks](attacks.md). How to run the review is [33-security-review](../33-security-review.md).

- **Repo rule.** ✅ a rule here, if followed, meets the item. 🟡 a rule meets part of it. ❌ no rule. ➖ the architecture as written has no such surface. 🏢 an organisational, people or physical control that an architecture cannot cover. **A tick is not a pass.** It says where to look; the reviewer still checks.
- **Tracker.** [owasp-top-10.csv](owasp-top-10.csv) has every row of every list below, with empty result columns.
- **Not yet released:** the OWASP MCP Top 10 is in beta as of November 2026. When it is released, map it here; it is the list closest to [27](../27-tool-servers-and-mcp.md).
